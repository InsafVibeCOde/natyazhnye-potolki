# Люкс Монтаж — натяжные потолки в Казани

Статичный сайт: HTML + CSS + JS, без сборки. GSAP, ScrollTrigger, Lenis и шрифты лежат локально (`js/vendor`, `fonts`), сайт не обращается к сторонним серверам.

- Демо: https://insafvibecode.github.io/natyazhnye-potolki/
- Обновление: изменить файлы → `git add -A && git commit -m "..." && git push`. После правок CSS/JS увеличьте `?v=` в ссылках на `css/style.css` и `js/main.js` в `index.html`, иначе браузеры покажут старую версию.

## Яндекс.Метрика

Сейчас выключена. Код уже готов: счётчик загружается **только после согласия** посетителя в баннере («Принять / Отклонить»), отказ удаляет cookie Метрики.

Как включить:

1. Создать счётчик в metrika.yandex.ru. Вебвизор можно включить, но **не включать запись содержимого полей** — имя и телефон не должны попадать в записи (поля формы дополнительно помечены классом `ym-disable-keys`).
2. В `js/main.js` вверху указать номер: `const METRIKA_ID = 12345678;`
3. В `html/privacy.html` заменить раздел 8 на текст из комментария над ним и обновить дату редакции.
4. В Метрике создать цель «JavaScript-событие» с идентификатором `lead` — это отправка заявки (без личных данных).
5. Увеличить `?v=` у `main.js` в `index.html`, закоммитить и запушить.

После включения в баннере появятся кнопки «Принять / Отклонить», ссылка на `html/cookie.html`, а в подвале — «Настройки cookie» для отзыва согласия.
