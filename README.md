# Люкс Монтаж — натяжные потолки в Казани

Статичный сайт: HTML + CSS + JS, без сборки. GSAP, ScrollTrigger, Lenis и шрифты лежат локально (`js/vendor`, `fonts`), сайт не обращается к сторонним серверам.

- Демо: https://insafvibecode.github.io/natyazhnye-potolki/
- Обновление: изменить файлы → `git add -A && git commit -m "..." && git push`. После правок CSS/JS увеличьте `?v=` в ссылках на `css/style.css` и `js/main.js` в `index.html`, иначе браузеры покажут старую версию.

## Настройки (`CONFIG` в начале `js/main.js`)

Пока поле пустое, связанный блок на сайте скрыт — пустых кнопок и выдуманных цифр не будет.

| Поле | Что даёт | Пример |
|---|---|---|
| `max` | кнопка «Отправить расчёт в MAX» в калькуляторе (только там). MAX не умеет открывать чат с готовым текстом, поэтому расчёт копируется в буфер и посетитель вставляет его сам | `'https://max.ru/u/…'` |
| `leadsEndpoint` | отправка заявок на сервер | `'server/send.php'` |
| `video` | видео с объекта в блоке «Готовый объект на видео». Пока пусто — плашка «скоро». Файл mp4 до ~10 МБ кладём в папку `video/` на своём хостинге, не YouTube | `{ src: 'video/obekt.mp4', poster: 'video/obekt.webp' }` |
| `rating` | рейтинг в полосе доверия | `{ value: '4,9', text: 'на Яндекс Картах', url: 'https://yandex.ru/maps/org/…' }` |
| `reviews` | блок отзывов (только реальные!). Сейчас выключен по решению заказчика — отзывы на картах, ссылки в подвале | `[{ name: 'Анна', text: '…', source: 'Яндекс Карты' }]` |
| `reviewsUrl` | ссылка «Все отзывы» | `'https://yandex.ru/maps/org/…/reviews/'` |
| `metrikaId` | Яндекс.Метрика, см. ниже | `12345678` |

## Приём заявок (`server/send.php`)

Работает на любом российском PHP-хостинге (Beget, Timeweb, REG.RU). Заявка сначала пишется в журнал `server/leads/leads-ГГГГ-ММ.csv` (открывается в Excel), затем уходит письмом на luxmontage@mail.ru. Если письмо не ушло — заявка всё равно сохранена, сайт показывает «Спасибо». Если сервер недоступен — посетитель видит номер телефона.

1. Залить сайт целиком на хостинг, проверить, что папка `server/leads` не открывается в браузере (закрыта `server/.htaccess`; на nginx закрыть её в настройках).
2. В `CONFIG` указать `leadsEndpoint: 'server/send.php'`, увеличить `?v=` у `main.js`.
3. Отправить тестовую заявку, проверить почту (и папку «Спам») и CSV.

На GitHub Pages PHP не работает — там заявки только выводятся в консоль браузера.
Пересылка заявок в Telegram-бота — это передача данных за рубеж: нужна отдельная подача уведомления в РКН.

## Яндекс.Метрика

Сейчас выключена. Код уже готов: счётчик загружается **только после согласия** посетителя в баннере («Принять / Отклонить»), отказ удаляет cookie Метрики.

Как включить:

1. Создать счётчик в metrika.yandex.ru. Вебвизор можно включить, но **не включать запись содержимого полей** — имя и телефон не должны попадать в записи (поля формы дополнительно помечены классом `ym-disable-keys`).
2. В `js/main.js` в `CONFIG` указать номер: `metrikaId: 12345678,`
3. В `html/privacy.html` заменить раздел 8 на текст из комментария над ним и обновить дату редакции.
4. В Метрике создать цель «JavaScript-событие» с идентификатором `lead` — это отправка заявки (без личных данных).
5. Увеличить `?v=` у `main.js` в `index.html`, закоммитить и запушить.

После включения в баннере появятся кнопки «Принять / Отклонить», ссылка на `html/cookie.html`, а в подвале — «Настройки cookie» для отзыва согласия.

## Персональные данные (152-ФЗ)

- Согласие — `html/agreement.html`, политика — `html/privacy.html`, cookie — `html/cookie.html`.
- Галочка согласия не отмечена по умолчанию, без неё заявка не уходит; в заявку пишется редакция согласия и время.
- Заявки принимает `server/send.php` на российском хостинге (см. выше): первичная запись — на сервере в РФ. Отправка напрямую в Telegram или на зарубежный сервис нарушает требование о локализации.
- Для боевого запуска — российский хостинг вместо GitHub Pages (серверы GitHub в США).
